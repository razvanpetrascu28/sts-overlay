# Optional informational features

Suggestions only. None of these are part of the current implementation request.

1. **Overkill** — Damage that exceeded the enemy's remaining HP, kept separate from useful damage.
2. **Unused block** — Block lost at turn start without absorbing damage.
3. **Overhealing** — Healing wasted because the target was already near full HP.
4. **Support map** — A player-to-player view of who gave whom block and healing.
5. **Action timeline** — Review a turn's plays and their resolved damage, block and healing.
6. **Enemy breakdown** — See damage dealt to each enemy and damage received from each enemy.
7. **Best turn** — Each player's highest-damage turn and strongest defensive turn.
8. **Debuff uptime** — Rounds for which effects such as Weak or Vulnerable remained active.
9. **Card chains** — Count observed draw, generation and replay chains between cards, without recommending plays.
10. **Draw droughts** — How many rounds have passed since a card was last drawn, and its longest recorded gap.
